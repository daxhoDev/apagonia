## Description

The Android home-screen widget of the mobile app ([MOBILE.md](MOBILE.md)).

## Decided so far

- An Android **home-screen widget** is provided.
- It shows the user's **subscribed circuits** with their **state and outage hours**.
- It is a **paid** feature ([PLANS.md](PLANS.md)).
- It refreshes whenever the app gets new data and periodically at the shortest interval Android allows for widgets.
